# ernur-qmj

Арнайы мерзімді кодпен жұмыс істейтін, №130 бұйрық нысанының міндетті тармақтарына негізделген ҚМЖ құрастыру сайты.

## Қазір жұмыс істейтіндері

- 1–11 сынып және уақытша 13 пәндік тізім;
- бөлім, тақырып және нақты оқу мақсатын енгізу;
- 45 минуттық бес бағанды ҚМЖ;
- әр тапсырмаға дескриптор мен балл;
- дене шынықтыруға арналған қауіпсіздік логикасы;
- OpenRouter немесе OpenAI API;
- API кілті жоқ кезде демо ҚМЖ;
- Word жүктеу, көшіру және басып шығару;
- телефонға бейімделген интерфейс.
- әкімші панелінде 1–365 күнге жарамды кіру кодын жасау;
- кодтарды көру, тоқтату, қайта қосу, ұзарту және жою;
- кодтың қолданылу саны мен соңғы қолданылған уақытын бақылау;
- мұғалімнің кіру кодын браузерде сақтау және мерзімін серверде тексеру.
- әр кіру кодын ең көбі екі құрылғыға (мысалы, телефон және компьютер) автоматты бекіту;
- әр кодқа әкімші панелінен 1–3 пән тағайындау және кейін пәндерді өзгерту;
- код иесіне тек рұқсат етілген пәндерді көрсету және басқа пән сұранысын сервер деңгейінде бұғаттау;
- үшінші құрылғыны бұғаттау және әкімші панелінен құрылғыларды босату;
- басты бетте автордың Kaspi картасы мен байланыс нөмірін көрсету және картаны бір басумен көшіру;
- мұғалім берген архивтен өңделген 275 бірінші тоқсан ҚМЖ-сы;
- КТЖ-дан алынған 5–11 сынып математикасы, алгебра және геометрияның 2–4 тоқсандарына арналған 1164 сабақ жазбасы;
- 2–4 тоқсандағы осы 1164 сабақтың әрқайсысына алдын ала дайындалған 45 минуттық ҚМЖ; сәйкес жазба табылғанда ЖИ API қолданылмайды;
- жүктелген «Атамұра» оқулықтарының сынып, пән және бөлім ретімен сәйкестендірілген 1164 жоспар;
- әр жоспарға тақырыпқа сай 4 нақты тапсырма және әр тапсырманың дәл астындағы баллдық дескриптор;
- мұғалім берген ҚМЖ құрылымы: ұйымдастыру 5 минут, сабақтың басы 10 минут, ортасы 25 минут, соңы 5 минут;
- 1-тоқсанда бірнеше жолға бөлінген негізгі жұмыстар мазмұны сақталып, осы төрт кезеңге біріктіріледі;
- сабақтың соңында бастапқы `5кл 39-40ат` үлгісіндей ББҮ кестесі арқылы қорытындылау беріледі;
- дескрипторлар 1-тоқсан мұғалімдік ҚМЖ үлгісіндей, тапсырма берілген кезеңде сол тапсырманың астында беріледі;
- `Бағалау критерийлері (әдістемелік толықтыру)` атты артық жол шығарылмайды;
- оқулық файлы мен ішкі бет сәйкестігі дерекқорда сақталады, бірақ ҚМЖ мәтінінде көрсетілмейді;
- геометрия, функция, бөлшек, пайыз, статистика және басқа көрнекілік қажет тақырыптардағы 953 жоспарға 24 түрдегі авторлық SVG сызбалар;
- көрнекіліктерді сайтта көрсету және Word жүктегенде PNG сурет ретінде құжаттың ішіне бірге енгізу;
- барлығы 1439 жазбаны сынып, пән, тоқсан, тақырып және оқу мақсаты бойынша автоматты сәйкестендіру;
- Ұлттық білім академиясының 2026–2027 әдістемелік нұсқау хатындағы математикалық сауаттылық, өмірлік мәнмәтін, шешімді тексеру және бірнеше стратегияны салыстыру ұсынымдарын ЖИ контекстіне қосу;
- мұғалімге база тізімін көрсетпей, пән, сынып, тақырып және оқу мақсаты арқылы сәйкес ҚМЖ-ны автоматты қолдану;
- база сәйкес келгенде ЖИ мәтінді қайта өзгертпей, мұғалімдік үлгінің мазмұнын 45 минутқа туралау;
- Word құжатын бастапқы базаға сай A4 тік форматта, Times New Roman қарпімен және 9/33/35/12/11 пайыздық бес бағанмен дайындау;
- Word-та мәтінді өзгертпей, кесте ұяшықтарының ішкі аралығы мен жол биіктігін ықшам көрсету;
- ЖИ қолжетімсіз болса, анықтамалық ҚМЖ негізінде 45 минуттық резервтік жоспар жасау.

Анықтамалық база сервердегі `data/qmj-reference-index.json` файлында сақталады және браузерге толық берілмейді. 1-тоқсан жазбалары мұғалім берген дайын ҚМЖ-дан, 2–4 тоқсан жазбалары мұғалім берген КТЖ-дан алынған. КТЖ бұрынғы оқу жылдарының материалдарын да қамтиды, сондықтан ол 2026–2027 ресми бағдарламасымен толық верификацияланған деп белгіленбейді. Сайт оқу мақсатын өздігінен ресми мақсат ретінде ойлап шығармайды. Архивтегі бір бос Word файлы (`11-сынып геометрия, 15–16-сабақ`) импортталмады.

Жаңа архивті қайта өңдеу:

```bash
python3 scripts/import_qmj_zip.py material.zip data/qmj-reference-index.json data/qmj-reference-report.json
python3 scripts/import_math_ktz_terms.py ktz.docx data/qmj-reference-index.json data/qmj-reference-index.json data/math-ktz-import-report.json
python3 scripts/build_prepared_math_plans.py data/qmj-reference-index.json
python3 scripts/generate_math_visuals.py
python3 scripts/enrich_atamura_plans.py data/qmj-reference-index.json
python3 scripts/restructure_teacher_template.py data/qmj-reference-index.json
```

## Компьютерде іске қосу

```bash
npm start
```

Сайт `http://localhost:3000` адресінде ашылады.

```text

OPENROUTER_API_KEY=сіздің_кілтіңіз

```

## OpenAI API

```text
AI_PROVIDER=openai
OPENAI_API_KEY=сіздің_кілтіңіз
AI_MODEL=gpt-4.1-mini
```

API кілтін GitHub файлдарына жазбаңыз. Оны Render сервисінің Environment бөлімінде сақтаңыз.

## Әкімші және кіру кодтары

Алдымен Supabase жобасының SQL Editor бөлімінде `supabase.sql` файлын орындаңыз. Содан кейін Render сервисінің Environment бөлімінде мына айнымалыларды орнатыңыз:

```text
ADMIN_PASSWORD=өзіңіздің_күрделі_құпиясөзіңіз
ACCESS_CODE_SECRET=кемінде_32_таңбалық_кездейсоқ_құпия
SUPABASE_URL=https://сіздің-жобаңыз.supabase.co
SUPABASE_SECRET_KEY=sb_secret_түріндегі_құпия_кілт
```

Әкімші беті: `/admin.html`. Мерзімді 1 күннен 365 күнге дейін тек күнмен енгізуге болады. Әкімші сессиясы 8 сағатқа жарамды. `ACCESS_CODE_SECRET` және `SUPABASE_SECRET_KEY` мәндерін сайт файлдарына немесе GitHub-қа жазбаңыз.

1.6 немесе одан жаңа нұсқаға алғаш өткенде жаңартылған `supabase.sql` файлын Supabase SQL Editor-де бір рет орындаңыз. Ол бұрынғы кодтарды жоймайды: екі құрылғы бағандарын сақтап, пәндік рұқсат бағанын қосады. Бұрыннан бар кодтарға бастапқыда «Математика» пәні беріледі; оны әкімші панелінен 1–3 пәнге өзгерте аласыз. 1.12 нұсқасындағы ҚМЖ құрылымы, ББҮ қорытындысы және Word суреттері үшін Supabase-те қосымша өзгеріс қажет емес.

Ескерту: 1.1 нұсқасындағы ұзын қолтаңбалы кодтар бұл басқарылатын дерекқор нұсқасында қолданылмайды. Панельден жаңа қысқа кодтар жасаңыз.
