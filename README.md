# ernur-qmj

Арнайы мерзімді кодпен жұмыс істейтін, №130 бұйрық нысанының міндетті тармақтарына негізделген ҚМЖ құрастыру сайты.

## Қазір жұмыс істейтіндері

- 1–11 сынып және уақытша 13 пәндік тізім;
- бөлім, тақырып және нақты оқу мақсатын енгізу;
- 45 минуттық бес бағанды ҚМЖ;
- әр тапсырмаға дескриптор мен балл;
- дене шынықтыруға арналған қауіпсіздік логикасы;
- OpenRouter немесе OpenAI API;
- API кілті жоқ кезде демо ҚМЖ;
- Word жүктеу, көшіру және басып шығару;
- телефонға бейімделген интерфейс.
- әкімші бетінде 1–365 күнге жарамды кіру кодын жасау;
- мұғалімнің кіру кодын браузерде сақтау және мерзімін серверде тексеру.

Пәндер мен оқу мақсаттарының нақты базасы мұғалім беретін материалдардан кейін `public/subjects.json` және бөлек мазмұн деректеріне енгізіледі. Сайт оқу мақсатын өздігінен ресми мақсат ретінде ойлап шығармайды.

## Компьютерде іске қосу

```bash
npm start
```

Сайт `http://localhost:3000` адресінде ашылады.

## OpenRouter Free

```text
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=сіздің_кілтіңіз
AI_MODEL=openrouter/free
```

## OpenAI API

```text
AI_PROVIDER=openai
OPENAI_API_KEY=сіздің_кілтіңіз
AI_MODEL=gpt-4.1-mini
```

API кілтін GitHub файлдарына жазбаңыз. Оны Render сервисінің Environment бөлімінде сақтаңыз.

## Әкімші және кіру кодтары

Render сервисінің Environment бөлімінде екі құпия айнымалы орнатыңыз:

```text
ADMIN_PASSWORD=өзіңіздің_күрделі_құпиясөзіңіз
ACCESS_CODE_SECRET=кемінде_32_таңбалық_кездейсоқ_құпия
```

Әкімші беті: `/admin.html`. Мерзімді 1 күннен 365 күнге дейін тек күнмен енгізуге болады. `ACCESS_CODE_SECRET` мәнін кейін өзгертпеңіз: ол өзгерсе, бұрын жасалған кодтар жарамсыз болады.

## Render

- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/api/health`

`render.yaml` жобамен бірге берілген.
